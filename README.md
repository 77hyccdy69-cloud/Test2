# Rankly – persönliche Ranglisten

Statische Web-App in einer einzigen Datei (kein Build nötig): `index.html` im Browser öffnen.

- Eigene Kategorien (Filme, Serien, Anime, Spiele, Bücher, beliebig viele eigene)
- Titel suchen → Cover und Kurzbeschreibung werden automatisch geladen (iTunes, TVmaze, AniList, Open Library, Wikipedia; optional TMDB/RAWG-Key in den Einstellungen)
- Ranking per Drag & Drop oder automatisch nach Bewertung, Podium für Platz 1–3, Listen- und Galerie-Ansicht
- Daten liegen lokal im Browser (localStorage), Export/Import als JSON
